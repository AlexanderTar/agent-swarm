# Swarm Note

Use `swarm_kb_write` only for a durable specification, approved plan, or decision. Choose the matching `specs`, `plans`, or `decisions` subdir, a descriptive filename, and a markdown body.
Include frontmatter fields: title, tags, task (if related), links.

Do not write progress updates, handoffs, review comments, summaries, transcripts, or tool output to the knowledge base; keep those on the task.
